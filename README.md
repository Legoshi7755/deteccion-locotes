# Detección de locotes — visión artificial

Repositorio para probar modelos de detección de locotes (*Capsicum pubescens*) con visión artificial.

## Estructura

```
deteccion-locotes/
├── src/                  # Código de implementación (inferencia, utilidades)
├── models/               # Pesos del modelo (.pt, .onnx, etc.)
├── data/
│   └── imagenes_prueba/  # Imágenes/videos para probar la detección
├── resultados/           # Salidas de las pruebas (imágenes anotadas, métricas)
└── tests/                # Pruebas automáticas
```
